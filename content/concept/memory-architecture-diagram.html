🧠 Intelligent Chatbot Memory System

Multi-Tier Hybrid Architecture | PostgreSQL + Neo4j + Redis + Qdrant + S3

💡 Why Multi-Tier Memory?

Modern LLMs need different types of memory for different tasks: fast access for ongoing conversations, semantic search for historical context, relationship intelligence for complex reasoning, and cold storage for compliance. This architecture combines the best of each technology to create a production-grade memory system.
