🔑 Key Architectural Decisions

  • Dual-Path Processing: Fast keyword check (10ms) runs first, with deep LLM evaluation running in parallel to main response
  • Non-Blocking Evaluation: User gets response quickly while crisis scoring happens asynchronously
  • Layered Memory: Four-tier memory (context window → session → user profile → RAG) balances richness with token limits
  • Tool Abstraction: Vercel AI SDK's tool system enables meeting search, mood logging, and resource retrieval
  • Safety-First: Multiple validation points (pre-flight, response safety, post-evaluation) prevent harmful outputs
  • Observable Everything: OpenTelemetry integration captures every interaction for debugging and improvement
  • Human-in-the-Loop: Crisis situations trigger alerts for human review while providing immediate automated support
  • Continuous Testing: Regression suite runs in CI/CD with golden datasets, LLM-as-judge metrics, and adversarial scenarios

⚡ Performance Targets

  • Pre-flight check: < 10ms
  • Main response (streaming): 200-500ms to first token
  • Crisis evaluation: 1-2 seconds (parallel, non-blocking)
  • Total user-perceived latency: 200-800ms

🛡️ Crisis Detection Thresholds

  • Level 1-3: Normal conversation, no action
  • Level 4-6: Elevated stress, log for monitoring
  • Level 7-8: High risk, inject crisis resources, flag for review
  • Level 9-10: Immediate danger, alert on-call team, emergency protocols
